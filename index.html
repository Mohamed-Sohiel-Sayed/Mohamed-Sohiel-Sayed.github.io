Team project · Real-time embedded

Power Window Control System with Safety Features

A car power-window controller on an ARM Cortex-M4 running FreeRTOS, with one-touch operation, a window lock and jam protection.

details
  • Controls the front passenger window from both the driver's and the passenger's panels: manual up/down while the button is held, and one-touch full open/close on a short press (under 1 second).
  • Jam protection: during a one-touch close, a detected obstacle stops the window and reverses it for 0.5 seconds. Top and bottom limit switches end every movement, and a lock switch disables the passenger panel.
  • FreeRTOS design: button, control and motor tasks for each panel, linked by binary semaphores and message queues, with timing based on the RTOS tick.
  • Register-level GPIO and UART drivers written from scratch (no vendor library); DC motor driven through an L298N H-bridge; UART and RGB LED status output for debugging.

Team project · Embedded / IoT

Li-Fi Home Security System

A home hazard monitor whose two microcontrollers talk through light instead of a wire.

details
  • A Tiva C (ARM Cortex-M4) reads a smoke sensor, a magnetic door sensor and an ultrasonic distance sensor.
  • Readings are sent over a Li-Fi link: the UART signal drives an LED, and a light receiver feeds an ATmega32 (AVR) board, which raises an LED and buzzer alarm and shows the event (smoke, intrusion, movement) on an LCD.
  • The same data goes to a phone over Bluetooth (HC-05) and appears in a serial terminal app as alerts and distance readings.
  • Interrupt-driven on/off and mute buttons; the mute command is sent over the light link to silence the receiver's alarm.
  • Bare-metal C on both boards with a layered MCAL/HAL design; the ultrasonic echo is measured with hardware timer input capture. Short-range prototype link at 9600 baud.

Solo project · Mobile

Hedieaty: Event and Gift List App

A Flutter app for wish lists: create events, list gifts, connect with friends and let them pledge gifts.

details
  • Users create events (sortable by name, date or status: upcoming, current, past) and gift lists for each event; friends can view published lists and pledge gifts.
  • Hybrid storage: private draft gifts are stored on the device in SQLite and moved to Cloud Firestore when published; both sources appear in one live list.
  • Pledging runs as a Firestore transaction, so a gift can't be pledged twice, and you can only pledge your friends' gifts, never your own. Pledged gifts are locked from editing and show who pledged them.
  • Firebase Authentication (email/password). Friends are added by phone number or from the phone's contacts, and can be found with search.
  • Layered code (models, controllers, services, views), animated page transitions, light and dark themes, input validation.
